4. A venv: what problem does it solve, and what did which python prove after you activated it?
5. What do the three lines in your .gitignore (.venv/, __pycache__/, .DS_Store) do, and why don't you commit .venv/?

8. is_admissible is written as one line: return (a + b) % 2 == 0 and a <= b. Why does it need no if statement — what type does that expression already produce?

 1. A pure function must not:

Change its inputs or any outside/global state.
Cause side effects, such as printing, writing to a file, or changing external data.

It should use its parameters to compute and return a result.

2. When another script runs import helpers, Python executes every top-level statement in helpers.py. Any top-level print() or function call would run immediately during the import, causing unwanted output or work before the importing script asks for it.

A helper module should therefore contain function definitions, not automatic actions: importing it should make the helpers available, while the calling script decides when to call them and what to print.

3. It does not see the new function because the current >>> session already imported and stored the older version of helpers.py in memory. Editing and saving the file changes the file on disk, but it does not automatically replace the version already loaded inside that running Python session.

exit()
python3

4. A virtual environment solves the problem of different projects needing different Python packages or versions without interfering with one another or with the system Python.

After activation, running:

which python

showed a path inside my project’s virtual environment, such as:

.../project/.venv/bin/python

That proved the shell was using the virtual environment’s Python interpreter rather than the system-wide one.

5. .venv/ tells Git to ignore the project’s virtual-environment folder.
__pycache__/ tells Git to ignore Python’s automatically generated bytecode-cache files.
.DS_Store tells Git to ignore the hidden metadata files macOS creates inside folders.

You do not commit .venv/ because it is large, machine-specific, and can be rebuilt from the project’s dependency list. You commit the source code and dependency instructions—not an entire local Python installation.

6. 
bs_diffs([5, 5, 2])

returns:

[0, 3]

because abs(5 - 5) = 0 and abs(2 - 5) = 3.

abs_diffs([7])

returns:

[]

A one-element list has no adjacent pair to compare, so the output length is len(values) - 1 = 0.

7. 

find_over_capacity({0: 3, 1: 1}, {0: 3, 1: 2})

returns:

[]

Vertex 0 is not included because its degree equals its capacity:

3 > 3   # False

The function uses strictly greater than (>), not greater than or equal to (>=). Vertex 1 is also within capacity because 1 > 2 is False.

8. It needs no if statement because the expression already evaluates to a Boolean value:

(a + b) % 2 == 0 and a <= b

Each comparison produces True or False, and and combines them into one final bool, so the function can return that result directly.
